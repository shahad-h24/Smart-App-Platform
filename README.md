Smart App Platform
1. Doel van het project

Het doel van dit project is het ontwikkelen van een Smart App Platform. Het platform bestaat uit een weerstation en 
een Smart App Controller.

De gebruiker kan weersgegevens invoeren, berekeningen uitvoeren en instellingen van verschillende systemen aanpassen.

2. Functionaliteiten
Weerstation

Bestand: weerstation.py

Temperatuur invoeren voor maximaal zeven dagen.
Celsius omrekenen naar Fahrenheit.
Gevoelstemperatuur berekenen.
Een weerrapport tonen.
De gemiddelde temperatuur berekenen.
Ongeldige invoer controleren.
Smart App Controller

Bestand: smart_controller.py

Het aantal dagen uit het invoerbestand tellen.
Automatische berekeningen uitvoeren.
CV-instellingen berekenen.
Ventilatie berekenen.
Bewatering bepalen.
Instellingen aanpassen en opslaan.
Weer API

Bestand: weer_api.py

Actuele temperatuur ophalen via de Open-Meteo API.
De actuele temperatuur in Utrecht tonen.
Hoofdmenu

Bestand: main.py

Het hoofdmenu tonen.
Het weerstation openen.
De Smart App Controller openen.
De actuele temperatuur ophalen.
Het programma afsluiten.
